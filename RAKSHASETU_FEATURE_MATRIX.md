## Technical Debt, Duplicate Services & Legacy Paths

1. **Duplicate Supabase Client Instances**:
   - `citizen/js/supabase-client.js` and `authority/src/services/supabase-client.js` both instantiate `@supabase/supabase-js`.
   - *Resolution*: Maintain both as single points of entry for their respective web applications, ensuring identical configuration (`persistSession: true`, safe public anon key).
2. **Obsolete WebSockets**:
   - `authority/src/services/websocketService.js` and `citizen/js/websocket-client.js` contain legacy port 5501 / Kotlin socket stubs.
   - *Resolution*: Supabase Realtime is the sole live event transport. Keep stubs inert to prevent import errors, but do not execute socket connections.
3. **Unlinked IndexedDB Schema**:
   - `offline-storage.js` creates an `outbox` store in IndexedDB, but `sync-manager.js` persists outbox items in `localStorage`.
   - *Resolution*: Consolidate queue storage into `OfflineQueue` using a robust dual-storage strategy (localStorage for speed and synchronous recovery, with IndexedDB for heavy telemetry).
4. **Hardcoded Language Strings in Assistant**:
   - `safety-assistant.js` contains hardcoded English text.
   - *Resolution*: Connect all assistant responses to `SafetyGuidanceService` backed by `citizen/i18n/` to ensure all 23 languages are supported seamlessly.
